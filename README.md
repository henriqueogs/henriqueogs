## Henrique Guimarães Santos · Senior Frontend Engineer

Senior Frontend Engineer with 9+ years building web applications, the last 6 focused on complex React + TypeScript products in banking, insurance, energy and industry.
Based in Brazil (UTC-3). Open to remote roles with US and European teams.

- 🏦 **Now:** React + TypeScript microfrontends (Module Federation) for the international accounts back-office at Banco Inter: high-value approvals, batch operations, multi-service reporting, permissions.
- 🛰️ **In production on the side:** [Monitor Ritápolis](https://ritapolis.com), a full-stack civic-tech platform. Scrapers and deterministic parsers over 2,300+ public documents, integration with Brazil's national procurement API (PNCP), LLM summaries and cross-document analysis, admin area with session auth.
- 💬 **Ask me about:** microfrontends, frontend architecture, API contracts between frontend and backend, testing strategy, shipping AI features into real products.
